## [ Сценарий 1 - Регистрация ]

1. Пользователь открывает сайт
2. Пользователь нажимает на кнопку регистрации
3. Сайт выводит форму регистрации
4. Пользователь вводит логин
5. Пользователь вводит пароль и подтверждает его
6. Если логин уже занят, сайт выдает ошибку и требует придумать другой логин
7. Если пароль слишком слабый, сайт выдает ошибку и требует придумать другой пароль
8. После успешной регистрации в базе данных создаётся новый пользователь с указанными данными
9. Сайт сообщает пользователю об успешной регистрации

---

## [ Сценарий 2 - Авторизация ]

1. Пользователь нажимает на кнопку авторизации
2. Сайт выводит форму авторизации
3. Пользователь вводит логин
4. Пользователь вводит пароль и нажимает на кнопку входа
5. Сайт ищет в базе данных пользователя с введённым логином и паролем
6. Если пользователь не найден, сайт выдаёт ошибку и сообщает, что логин или пароль введены неверно
7. Если пользователь с введенными данными найден, сайт выдаёт временный токен этого пользователя
8. Сайт сообщает пользователю об успешной авторизации

---

## [ Сценарий 3 - Просмотр статьи ]

1. Пользователь переходит в раздел "Статьи"
2. Сайт отображает список статей (заголовок + тема)
3. Пользователь выбирает статью
4. Сайт открывает страницу статьи и рендерит её с поддержкой markdown
5. Пользователь читает статью 
6. В "подвале" статьи могут быть прикреплены ссылки на задания по теме статьи
7. Пользователь завершает чтение статьи
8. Пользователь нажимает на кнопку в концеи статьи, чтобы отметить, что он прочитал статью
9. Сайт сохраняет id статьи в базе данных в записи пользователя

---

## [ Сценарий 4 - Скачивание задания ]

1. Пользователь переходит в раздел "Задания"
2. Сайт отображает список заданий ( Название + уровень сложности)
3. Если пользователь вошёл в аккаунт с решенными заданиями, решенные задания будут помечаться 
4. Пользователь выбирает задание
5. Пользователь нажимает на задание
6. Пользователя перекидывает на страницу задания с названием, кратким описанием, полем для ввода флага, кнопкой скачивания контейнера, инструкцией по развертке контейнера и свернутыми подсказками
7. Пользователь нажимает на кнопку скачивания контейнера
8. Сайт начинает отправляет пользователю контейнер с уязвимым приложением
9. Пользователь, следуя инструкциям на странице задания, развертывает контейнер
10. Пользователь приступает к решению

---

## [ Сценарий 5 - Решение и сдача флага ]

1. Пользователь анализирует работу приложения в контейнере
2. Пользователь находит уязвимость
3. Пользователь получает доступ к флагу
4. Пользователь копирует найденный флаг
5. Пользователь возвращается на страницу задания на сайте
6. Пользователь вводит флаг в специальное поле и нажимает на кнопку сдачи флага
7. Если флаг неверный, сайт выдает ошибку и предлагает повторить попытку
8. Если флаг верный, сайт отмечает задание как выполненное и обновляет запись пользователя в базе данных, добавляет id задания в колонку выполненных заданий
9. Если пользователь выполнил задание, но не вошел в аккаунт, то просто получит сообщение, что задание выполнено

---

## [ Сценарий 6 - Просмотр профиля и статистики ]

1. Пользователь входит в свой аккаунт
2. Пользователь переходит в свой профиль
3. Сайт берет статистику и данные пользователя из базы данных
4. Пользователь видит свою статистику: сколько заданий он выполнил, сколько статей прочитал и т.д.
5. Сайт отображает общий прогресс обучения в процентах
6. Пользователь анализирует свою статистику
7. Сайт предлагает пользователю перейти к следующей статье ( будет предложена первая непрочитанная относительно всего списка статей )

---

## [ Сценарий 7 - Сортировка заданий ]

1. Пользователь переходит в раздел заданий
2. Пользователь настраивает фильтры заданий, отсортировать по сложности, по теме, по дате, скрыть выполненные задания, поиск по названию
3. Пользователь может применить несколько фильтров одновременно
4. Пользователь нажимает на кнопку поиска
5. Сайт создаёт запрос в базу данных для получения списка заданий, учитывая фильтры пользователя
6. Сайт возвращает список заданий с учетом фильтров
7. Пользователь выбирает задание

---

## [ Сценарий 8 - Использование подсказок и решения ]

1. Пользователь переходит на страницу задания
2. Пользователь пытается сам решить задание
3. Если пользователь не смог решить задание самостоятельно, он переходит к подсказкам из "подвала" задания
4. Пользователь открывает первую подсказку ( все подсказки "свернуты", чтобы не спойлерить решение пользователю )
5. Отправляется запрос на сервер, пользователь получает данные всех подсказок и готовое решение
6. Пользователь открывает следующие подсказки, если считает это необходимым ( открыть готовое решение, не открыв все подсказки до него, нельзя )
7. Если даже с подсказками пользователь не смог решить задание, он открывает готовое решение
8. Пользователь ознакамливается с ходом решения, анализирует идею задания и по желанию дорешивает задание, зная идею

---

## [ Сценарий 9 - Раздел материалов от других авторов ]

1. Пользователь заходит на сайт
2. Пользователь нажимает на кнопку "Прочие материалы" в шапке сайта, шапка доступна с любой страницы сайта
3. Пользователь попадает на страницу, где собраны различные полезные материалы по теме информационной безопасности ( ссылки с комментариями на статьи, книги, видео, курсы и тд)
4. Отправляется запрос на получение всех ссылок, заголовков и комментариев к материалам с бекенда
5. Пользователь ознакамливается с доступными материалами (ссылками, заголовками, комментариями, коротко о чем тот или иной материал и в чем он хорош), формат страницы похож на awesome лист
6. Пользователь выбирает интересный ему материал
7. Пользователь переходит по прикрепленной на материал ссылке и попадает на сторонний ресурс
8. Пользователь ознакамливается с содержимым ( статьи, видео, книги и тд )
