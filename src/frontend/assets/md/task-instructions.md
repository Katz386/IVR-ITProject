Перед запуском убедитесь, что порт 8000 не занят [http://localhost:8000](http://localhost:8000)

1. Нажмите **Скачать архив** чтобы скачать архив, да
2. Распакуйте его в папку. Внутри лежит код и файл **docker-compose.yml**
3. Для запуска приложения потребуется **Docker** и **Docker compose**

### Запуск приложения

Откройте терминал в папке распакованного архива и выполните:

```
docker compose up -d --build
```

(Приложение будет работать на фоне, без вывода в консоль)

Первый запуск может быть долгим из-за скачивания и сборки нужных образов

### Перейдите к заданию

Откройте [http://localhost:8000](http://localhost:8000)

Проанализируйте приложение, найдите флаг и отправьте его в форме **Отправить флаг**. Если возникнут трудности, можете открыть подсказки (Лучше, конечно, без них)

### Остановка приложения

!!! НЕ ОСТАВЛЯЙТЕ УЯЗВИМОЕ ПРИЛОЖЕНИЕ ЗАПУЩЕННЫМ !!!

ОБЯЗАТЕЛЬНО ВЫПОЛНИТЕ ЭТИ ДЕЙСТВИЯ:

После завершения работы выполните в той же папке:

```
docker compose down --volumes --rmi all --remove-orphans
```

Не запускайте несколько заданий одновременно, они все слушают один и тот же порт и будут конфликтовать
