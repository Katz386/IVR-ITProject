[OWASP top 10](https://top10.owasp.org/) - отчет проекта OWASP о распространенных ошибках и уязвимостях в веб приложениях. Обновляется каждый год

[Roadmap.sh CS](https://roadmap.sh/cyber-security) - большая дорожная карта по инфобезу. Собрано много тем и материалов, рекомендую читать параллельно с решением тасок на этом сайте

[Hacktricks](https://hacktricks.wiki/en/index.html) - сборник статей по инфобезу, собраны интересные техники и уязвимости. Перед тем как начать читать, желательно уже иметь какие-то знания по ИБ. Рекомендую начать с раздела по вебу (Pentesting Web), а к другим разделам переходить уже по мере необходимости

[SpbCTF](https://vk.ru/@spbctf-ctf-for-beginners) - (**ССЫЛЬ НА ВК!!!**) старенький, но рабочий курс по CTF, хорошо подойдет начинающим (подойдет и тем, кого ctf не интересует). Курс большой, затрагивает много тем. Не знаете с чего начать - начинайте с веба

[pwn.college](https://pwn.college/) - большая beginner friendly платформа для изучения инфобеза, много теории, много практики. Куча разных тем, ctf, веб безопасность, binary exploitation. Очень много заданий, хорошая обучалка для начинающих, крайне рекомендую

[OverTheWire](https://overthewire.org/) - не самая бегиннер френдли платформа, но есть много заданий, которые охватывают разные темы ИБ. Есть задания на практику, если Вы уже что-то умеете - будет полезно порешать

[WeChall](https://www.wechall.net/) - старенький сайт для опытных ctf`еров. Сложно его как-то одним словом описать... НАБОР ШТУК))) по инфобезу, задания, форум, постоянно пополняется сборник других платформ по ИБ. Опытные безопасники в целом смогут что-то интересное для себя найти. Сайт старый, но живой

[CTF WiKi](https://ctf-wiki.org/en/) - маленький сайт по темам CTF. Информации мало, если нечего делать вечером - можно почитать. Сайт на китайском, не пытайтесь его переводить встроенным в сайт переводчиком - он не работает :) Переводите встроенными в браузер переводчиками (лучше на английский)

[Awesome CTF](https://github.com/apsdehal/awesome-ctf?utm_source=chatgpt.com) - набор инструментов для решения ctf заданий, набор материалов и обучающих платформ по ctf. Пропускайте, если не знакомы с концепцией awesome проектов. Подойдет только тем, кто уже умеет что-то решать, нужно знать что Вы хотите от репы

[Hackerone Hacktivity](https://hackerone.com/hacktivity/overview) - hackerone помогает другим компаниям безопасно и удобно имплементировать программу (не в знач. ПО) Bug Bounty. Эта программа позволяет, грубо говоря, случайным людям в интернете безопасно и в рамках закона исследовать на наличие уязвимостей ресурсы компании, которая проводит программу bug bounty (разумеется, за найденные уязвимости компании платят деньги их нашедшим). Hackerone Hacktivity - это раздел сайта hackerone, в котором согласные на публикацию компании публикуют отчеты независимых исследователей безопасности о найденных уязвимостях. Очень полезно будет почитать тем, кто хочет строить карьеру в ИБ, для обычных CTF и олимпиад это бесполезно, увы (рекомендую отчеты про curl игнорировать :)
